How to use

  1. Link tokens/tokens.css then assets/components.css.
  2. Use the class names shown on each component page; every state has a data-state hook for documentation only.
  3. Consume tokens/tokens.json (DTCG) from design tools and build pipelines.
  4. In the Angular workspace the TypeScript theme remains the product source of truth; this system is the reference it mirrors.
