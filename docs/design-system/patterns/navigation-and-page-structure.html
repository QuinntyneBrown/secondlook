Navigation and page structure

The shell, page header, breadcrumbs, tabs versus pages and back behaviour.

WCAG 2.2 AAStatus: stable
  • Overview
  • When
  • Structure
  • States
  • Responsive

Overview

Every page has a skip link, a topbar, a main landmark with one h1, and a footer. Wizards use a stepper instead of the primary nav.

When to use which

NeedUse
Top-level destinationsTopbar nav (5 or fewer)
Sibling settings pagesSidebar
Two to five views of one recordTabs
Position in a hierarchyBreadcrumb
Linear taskStepper and Back

Structure

  1. Inspections
  2. Report

2016 Honda Civic LX

States

  • The current location is always marked with aria-current.
  • Back returns to the previous step with answers preserved.

Responsive behaviour

On phones the primary nav wraps to its own row and the sidebar hides behind a menu button.

Accessibility

Landmarks: header, nav (labelled), main, footer. Heading levels never skip. Focus moves to the h1 after in-app navigation.

Content

Navigation labels are nouns and match page titles.
