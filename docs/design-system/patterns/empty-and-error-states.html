Empty and error states

Copy formulas and layouts for nothing-to-show and something-went-wrong.

WCAG 2.2 AAStatus: stable

Overview

Every list, report and page has a designed empty and error state. They are calm, specific and offer one next step.

When to use which

StateTreatment
First runEmpty state with the creating action
No resultsCompact empty with Clear filters
Permission403 page, explain who can see it
Load failedError empty with Try again
OfflineBanner plus cached content
Not found404 page

Structure

No matching inspections

Try removing a filter.

States

  • First run invites; no results explains; error recovers.

Responsive behaviour

Empty states centre in their container and shrink to empty--compact inside cards.

Accessibility

The title is a heading; the action is a real button or link; error text is not announced as an alert unless it appears after an action.

Content

Title says what is missing, one sentence says why, one action moves forward.
