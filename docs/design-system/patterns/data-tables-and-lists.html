Data tables and lists

Density, sorting, selection and responsive strategy for records.

WCAG 2.2 AAStatus: stable
  • Overview
  • When
  • Structure
  • States
  • Responsive
  • Accessibility
  • Content
  • Do and don't
  • Sources

Overview

Few records read best as a list; many records compared by value belong in a table. Tables scroll inside their wrapper on phones.

When to use which

RecordsUse
Fewer than ten, one main action eachList
Many, compared by valueTable
More than twentyTable with pagination
Read-only facts about one thingDescription list

Structure

Receipts
DateAmount
28 Oct$45.00

States

  • Loading: skeleton rows. Empty: empty state in place of the body. Error: error empty with Try again.

Responsive behaviour

The table scrolls horizontally inside .table-wrap; lists wrap meta under the title.

Accessibility

Captions name tables; sortable headers use aria-sort with a real button; row actions are reachable by keyboard.

Content

Numbers right-aligned, dates consistent, status as a pill with text.
