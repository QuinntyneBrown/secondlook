Typography

IBM Plex Sans and Mono in a nine-step rem scale, with role shorthands that components consume whole.

WCAG 2.2 AAStatus: stable

Overview

One family, IBM Plex Sans, with IBM Plex Mono for money, VINs and codes. Eleven role shorthands (--text-*) bundle weight, size, line height and family so a component writes font: var(--text-body) and nothing else. Sizes are in rem so they follow the reader's browser setting.

Line heights: tight 1.2 for display, h1 and h2; snug 1.3 for h3 and h4; normal 1.5 for body; relaxed 1.65 for long reading.

Measure

Paragraphs are capped at --layout-measure (65ch) so lines stay readable at any width. Tables, cards and form controls are not capped.

Usage rules

  • Sentence case everywhere, including buttons, headings and table headers.
  • One h1 per page; never skip a heading level for looks.
  • Money and identifiers use .money / .mono so digits align (tabular numbers).
  • Never go below --font-size-xs (12px); body copy is 16px.

Accessibility

Sizes are relative, so browser zoom and larger default text work without breaking layouts (WCAG 1.4.4). Nothing breaks at the 1.4.12 text-spacing overrides: containers grow with their text. Large text (≥ 24px, or ≥ 18.7px bold) needs 3:1, everything else 4.5:1.

Responsive type

Type does not scale with the viewport. Headings wrap with text-wrap: balance; the display style (48px) is used on marketing heroes and drops to --font-size-4xl below the medium breakpoint.
