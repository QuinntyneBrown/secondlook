Responsive

Mobile-first rules, per-component behaviour at each breakpoint and a testing matrix.

WCAG 2.2 AAStatus: stable
  • Overview
  • Breakpoint behaviour
  • Touch rules

Overview

Mobile first: base styles are for a 360px phone and media queries only add (min-width). Most SecondLook buyers are on a phone while standing in a driveway, so the booking flow, call lobby and estimate report are designed at 360px first.

Breakpoint behaviour

ComponentBelow md (768px)md and up
TopbarBrand and menu on the first row; primary nav on its own rowSingle row
DialogFull-width bottom sheetCentred panel (sm / md / lg)
Sidebar layoutSidebar stacks above contentFixed sidebar beside content
Data tableScrolls inside .table-wrapFull width
Booking wizardSingle column, order summary after the formForm beside sticky order summary
Call layoutStage first, controls under it, side panel belowStage with side panel
Slot grid2–3 columnsAuto-fill at 6.5rem

Touch rules

  • Targets are at least 24×24px (--target-min) and primary mobile actions 44×44px (--target-comfortable).
  • No interaction depends on hover; tooltips also open on focus.
  • Bottom navigation honours the iOS safe area; see the ADR on bottom-nav chrome before changing it.

Reflow

Everything works at 320px CSS width with no horizontal page scroll (1.4.10). Long text uses .truncate or wraps; never fixed widths.
