Spacing

A 4px scale and the rules for what sits close together and what sits apart.

WCAG 2.2 AAStatus: stable
  • Overview
  • The scale
  • Inside versus between
  • Control heights
  • Usage rules
  • Tokens

Overview

A 4px base scale (--space-1 = 4px) with a half step at 2px. Spacing communicates grouping: tight inside a component, loose between components.

Inside versus between

RuleValueExample
Gap between a label and its control--space-1Field label to input
Gap between related controls--space-2 to --space-3Buttons in a row, chips
Padding inside a card or panel--space-4 to --space-6Card, dialog body
Gap between fields in a form--space-4Stacked form fields
Gap between page sections--space-8 to --space-12Marketing bands, report sections

Rule of thumb: space between groups is at least twice the space inside them.

Control heights

Buttons, inputs and selects share --control-height-sm/md/lg so they align in a row.

Usage rules

  • Use a scale token for every margin, padding and gap. No raw pixel values in component CSS.
  • Use gap on flex and grid containers instead of margins on children, except the final collapse spacing in .stack.
  • Off-grid values found in the mocks were snapped to the scale (see the drift log).
