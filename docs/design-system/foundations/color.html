Color

A warm neutral ramp, one orange accent and four status tones, expressed as semantic roles that flip cleanly between light and dark.

Overview

SecondLook is warm paper and asphalt with one orange accent. Colour is organised in three tiers: primitives (--palette-*, never used by components), semantic roles (--color-*, what components read) and component tokens (--btn-bg, declared in components.css, always an alias of a role). Dark mode re-points the roles; the primitives never change.

Status is never colour alone: every status pairs a role colour with an icon and text, and the checker enforces 4.5:1 for text and 3:1 for UI edges in both themes.

Primitive ramps

Five ramps. The blue ramp name is a legacy of the starter kit: its values are the orange Signal accent (see the drift log in the README). Use the role tokens, never the ramp steps.

Usage rules

  • Components read --color-* roles only. A raw hex or a --palette-* step in a component is a bug.
  • Accent orange marks the one primary action per view and the selected state. Do not use it for decoration.
  • Status colour always travels with an icon and a text label.
  • The price panel, the video stage and the logo tile are deliberately theme-invariant (they read primitives). They are the only exceptions.

Adding a brand theme

Copy the [data-theme="dark"] block in tokens.css, rename it, override only role tokens, then run check_contrast.py. Do not add new roles for one theme.
