Iconography

A small stroke-icon set on a 24-unit grid that inherits colour from its text.

WCAG 2.2 AAStatus: stable
  • Overview
  • Sizes
  • Icons used in the mocks
  • Labelling rules
  • Usage rules

Overview

Icons are inline SVG on a 24-unit grid with a 2px round stroke, drawn in currentColor so they inherit the text colour and theme. They support text; they do not replace it.

Sizes

.icon--sm 16px, .icon 20px, .icon--lg 24px and up inside empty states.

Labelling rules

  • Decorative icon next to text: aria-hidden="true".
  • Icon-only control: the button carries aria-label; the SVG stays hidden.
  • An icon that carries meaning on its own (status) is always paired with visible text.
  • One icon, one meaning: the car is always a vehicle.

Usage rules

  • Copy the path data from this sheet; do not import an icon font.
  • Do not tint icons with a status colour unless the text beside them says the same thing.
  • The SecondLook logo mark has its own colour wiring (--logo-*) so the tile flips in dark mode.
