Elevation

Shadow levels, surface roles and a named z-index scale.

WCAG 2.2 AAStatus: stable
  • Overview
  • Shadow levels
  • Surface hierarchy
  • Z-order
  • Usage rules
  • Tokens

Overview

Four shadow levels plus a focus ring. Elevation tells the reader what sits above what: cards at level 1, menus and popovers at 3, dialogs at 4. In dark mode shadows get stronger and raised surfaces also get lighter, because shadows alone are invisible on dark canvases.

Z-order

LayerTokenValue
Base--z-base
Raised--z-raised
Sticky--z-sticky
Dropdown--z-dropdown
Overlay--z-overlay
Modal--z-modal
Popover--z-popover
Toast--z-toast
Tooltip--z-tooltip

Never write a raw z-index. Stacking order: sticky bars, dropdowns, overlay backdrop, modal, popover, toast, tooltip.

Usage rules

  • Pair every shadow with a 1px border on surfaces that must stay legible in forced-colors mode.
  • Toasts sit above dialogs so a confirmation is never hidden.
  • The focus ring (--shadow-focus) is not elevation; it is always visible and never removed.
