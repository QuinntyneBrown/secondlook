Layout and grid

Breakpoints, a 4/8/12 column grid, gutters, margins and the page templates the product uses.

WCAG 2.2 AAStatus: stable

  • Breakpoints, columns, gutters, margins
  • Live grid

Overview

Mobile first. Content sits in a container capped at --layout-container-max (80rem). The column count, gutter and margin step up at the medium and large breakpoints. The booking flow uses a narrower wizard column; the live call uses a stage plus a side panel.

Usage rules

  • The topbar is --layout-topbar-height (3.5rem); on phones the primary nav drops to its own row.
  • Never rely on hover to reveal layout; everything stacks to one column at 320px with no horizontal scroll (tables scroll inside .table-wrap).
  • Set scroll-padding-top to the topbar height so focused elements are never hidden behind it.
