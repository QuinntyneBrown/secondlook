Shape

Six corner radii and two border widths, mapped to element types.

WCAG 2.2 AAStatus: stable
  • Overview
  • Radius scale
  • Which radius for what
  • Border widths
  • Usage rules
  • Tokens

Overview

Corners are soft but restrained: six radii, from a 2px nick to a full pill. Borders are 1px by default and 2px for emphasis and focus.

Radius scale

--radius-xs
--radius-sm
--radius-md
--radius-lg
--radius-xl
--radius-full

Which radius for what

ElementRadius
Checkbox, small inner chips--radius-xs
Tooltips, tags, small inputs--radius-sm
Buttons, inputs, menus, alerts--radius-md
Cards, popovers, tables--radius-lg
Dialogs, price panel, hero art--radius-xl
Pills, badges, avatars, switches--radius-full

Border widths

--border-width-hairline (1px) for dividers and control edges; --border-width-thick (2px) for selected cards, stepper nodes and the focus ring.

Usage rules

  • Nested corners subtract the padding: an inner element's radius is the outer radius minus the gap.
  • Form control edges use --color-border-strong (3:1); decorative card edges use --color-border-default.
