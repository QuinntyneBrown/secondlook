Table

Tabular records such as receipts, with sortable columns and row actions.

Overview

Use a table for data compared across rows and columns. On phones it scrolls inside its wrapper. For a handful of records, a list reads better.

Anatomy

  1. Wrapper.table-wrap scrolls horizontally.
  2. CaptionVisually hidden name.
  3. Header cellscope="col", sticky.
  4. Row actionsRevealed on hover and focus.

Variants

Receipts with numeric column and status.

Sizes

Row height is set by padding; one density.

States

Pointer and focus states are forced here with data-state so they can be reviewed without a mouse; real pages get them from :hover, :focus-visible and :active. Attribute states (aria-*, disabled) are the real ones.

Responsive behaviour

Data components truncate or wrap long text and never force horizontal page scroll; tables scroll inside their own wrapper.

Theming

Colours come from semantic roles, so the component flips with the theme and needs no dark-mode rules of its own. Re-theme it by overriding its component tokens on a parent, never by editing the component.

Accessibility

Role and pattern

Native <table> with caption and scope; sort via aria-sort.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to or from the control in reading order.
EnterActivates the control.
SpaceActivates the sort button.

Focus

Row actions become visible when a descendant has focus.

Labelling

Caption names the table; numeric columns right-aligned.

Contrast

Row text
Header text

Motion

Colour and background transitions use --duration-fast; under prefers-reduced-motion they are effectively instant.

Touch

Hit area is at least --target-min (24px) and 44px for primary mobile actions.

Content

Header cells are nouns. Money right-aligned in mono; dates in a consistent format.
