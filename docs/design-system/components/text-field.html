Text field

A single-line input for short text, email, password, number or VIN.

Overview

Use a text field for free text of a line or less. Use a textarea for more, a select for a fixed list. Every field sits in a form field wrapper that supplies label, help and error.

Anatomy

  1. LabelAlways visible, above the control.
  2. Control40px tall, 1px strong border.
  3. Help textLinked with aria-describedby.
  4. Error textReplaces help; icon plus words.

Variants

Match the input type to the data so mobile keyboards and autofill help.

Text, email, password, number
HTML
<div class="field"><label class="field__label" for="tf1">Full name</label><input class="input" id="tf1" autocomplete="name"></div><div class="field"><label class="field__label" for="tf2">Email</label><input class="input" id="tf2" type="email" autocomplete="email" placeholder="name@example.com"></div>

Sizes

Three heights match buttons so they align in a row.

States

Pointer and focus states are forced here with data-state so they can be reviewed without a mouse; real pages get them from :hover, :focus-visible and :active. Attribute states (aria-*, disabled) are the real ones.

Responsive behaviour

Inputs fill their container (never fixed width) and stack one per row below the medium breakpoint. Heights stay at 40px or more so touch targets are comfortable.

Theming

Colours come from semantic roles, so the component flips with the theme and needs no dark-mode rules of its own. Re-theme it by overriding its component tokens on a parent, never by editing the component.

Accessibility

Role and pattern

Native <input> with a <label for>. Errors use aria-invalid and aria-describedby.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to or from the control in reading order.
TypeEnters text.
EscIn search fields, clears the value.

Focus

The border turns to the focus colour and a 2px ring is drawn inside the control.

Labelling

Visible label always; placeholders are examples, never labels. Required fields say “required” in the label.

Contrast

Control edge on surface
Placeholder on surface
Error text on canvas
Focus ring on surface

Motion

Colour and background transitions use --duration-fast; under prefers-reduced-motion they are effectively instant.

Touch

Controls are 40px tall (48px large); the label is part of the hit area.

Content

Labels are nouns (Email, VIN). Help says where to find it. Errors say how to fix it (see Content).
