Select

A native dropdown for choosing one option from a list.

Overview

Use the native select for five to fifteen options. Fewer than five: radios. More: a search combobox.

Anatomy

  1. LabelVisible, above.
  2. ControlNative <select> with chevron.
  3. OptionsRendered by the platform.

Variants

Always native, so mobile pickers work.

Default with placeholder option
HTML
<div class="field"><label class="field__label" for="s1">Model year</label><select class="select" id="s1"><option value="">Choose a year</option><option>2016</option><option>2015</option></select></div>

Sizes

Matches the text field height.

States

Pointer and focus states are forced here with data-state so they can be reviewed without a mouse; real pages get them from :hover, :focus-visible and :active. Attribute states (aria-*, disabled) are the real ones.

Responsive behaviour

Inputs fill their container (never fixed width) and stack one per row below the medium breakpoint. Heights stay at 40px or more so touch targets are comfortable.

Theming

Colours come from semantic roles, so the component flips with the theme and needs no dark-mode rules of its own. Re-theme it by overriding its component tokens on a parent, never by editing the component.

Accessibility

Role and pattern

Native <select>.

Keyboard

KeyAction
Tab / Shift+TabMoves focus to or from the control in reading order.
↑ / ↓Changes option.
Alt+↓Opens the list.

Focus

Ring as for inputs.

Labelling

Visible label; the first option is a prompt with an empty value.

Contrast

Control edge on surface
Body text on surface

Motion

Colour and background transitions use --duration-fast; under prefers-reduced-motion they are effectively instant.

Touch

Hit area is at least --target-min (24px) and 44px for primary mobile actions.

Content

Options are sorted logically (years descending, alphabetical names).
